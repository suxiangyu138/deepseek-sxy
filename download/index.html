DeepSeek_sxy

自带 API Key、数据只存本机的 DeepSeek 客户端。绕开 C 端每日额度，上下文 1M。

为什么是它

不受每日额度限制

官方 App 与网页版从 2026 年 11 月起限制每日对话额度、单次约 4 万字输入。这里用你自己的 API Key 直连，按量计费，没有 C 端配额。

对话永远在你手里

会话、记忆、图片只存在设备本地。没有账号、没有云同步，删应用即清空，不存在「7 天不活跃就续不上」。

能力对齐官方客户端

深度思考、联网搜索、阅读链接、图片识别、PDF 与 Office 解析，全部走官方接口，模型是 V4.1 Flash / V4 Pro。

1M 上下文可感知

每条回答显示缓存命中率、输出速率与费用，顶栏实时显示上下文占用，不用猜还剩多少。

安装

1
下载安装包

点击上方按钮，浏览器提示「可能有害」时选择仍然下载。

2
允许未知来源

打开文件后系统会提示，前往设置允许当前浏览器安装，然后返回继续。

3
填入自己的 Key

首次打开填入 DeepSeek API Key，在设置里点「测试连接」确认可用。
