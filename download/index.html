下载 Android 安装包
版本 1.0.0 · 约 8MB · 需要 Android 8.0 及以上

安装步骤

  1. 点上面的按钮下载 APK
  2. 浏览器提示「可能有害」时选择「仍然下载」
  3. 打开文件，系统提示「未知来源」，点「设置」允许本次安装
  4. 安装完成后打开，填入自己的 DeepSeek API Key

隐私

API Key、对话记录、记忆全部保存在你自己的手机上，不经过任何服务器。本页面只提供安装包下载。

常见问题

安装失败：确认系统版本 ≥ Android 8.0，并在「设置 → 应用 → 特殊权限 → 安装未知应用」里允许当前浏览器。
无法发送消息：检查 API Key 是否有效、账户是否有余额，可在应用「设置 → 测试连接」里验证。
